# HASH@HUNTER — Free Edition

**Your AI. Our Tools. Your Infrastructure.**

[Official website](https://hashtager.tech) · [Releases](https://github.com/MrShadow909/Hash-hunter-free/releases) · [Feedback](https://github.com/MrShadow909/Hash-hunter-free/issues)

HASH@HUNTER is a standalone, AI-ready security automation toolkit by HashTager Technology. Use the CLI or connect a compatible local MCP client, such as Codex. The engine does not require its own AI provider.

## Capabilities

| Module | Purpose |
| --- | --- |
| Scope & Doctor | Authorization boundaries and dependency diagnostics |
| OSINT | Passive public-source intelligence |
| Recon | Authorized asset inventory |
| Web assessment | Authorized web security assessment |
| Network assessment | Authorized network service inventory |
| Fusion | Evidence normalization and deduplication |
| Report | JSON and Markdown reports |
| MCP | Tool discovery and operator-controlled integration |

External assessment tools are customer-installed (BYOT). Active assessment requires an explicitly authorized scope and operator approval. Scanner observations are not confirmed vulnerabilities. Autonomous exploitation, credential attacks and unrestricted shell access are not included.
